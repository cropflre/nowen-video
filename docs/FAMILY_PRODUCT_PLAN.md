# Nowen Video 家庭观影产品方案

日期：2026-10-26
状态：P0 与部分 P1/P2 已实施；儿童独立账号及服务端内容隔离已落地，见 [儿童空间实施记录](qa/child-space-2026-10-27.md)。上一阶段范围见 [家庭观影实施记录](qa/family-product-2026-10-26.md)。真实家庭用户与设备验收仍待完成。

## 1. 产品定位与取舍

**家人打开就会用的私人家庭影院。有人负责添加影片，所有人都能轻松找到、播放和接着看。**

“又懒又蠢”转化为设计约束：假设用户没有技术背景、不读说明、不记路径、注意力有限、可能看不清或点错。由产品承担记忆和判断，界面文案保持尊重。年龄与职业不作为操作能力的替代指标。

首要服务四类使用场景：自己追剧、长辈找熟悉的片、家长给孩子选内容、全家一起看。按场景设计，不为各行业建立独立模式。

家庭自托管有真实边界：需要有人完成部署、连接存储、提供影片。第一阶段承诺“家人无需配置即可观看”，管理员目标是“一次引导、日常少维护”。若要做到无人懂技术也能从零使用，后续需要另立安装交付方案，不能仅靠首页改版达成。

核心取舍：先把已有影片的观看闭环做好；AI、复杂统计、精彩片段等作为可选增强。保留高级能力，但不要求普通观众理解它们。

## 3. 统一的信息架构

普通观众的四个主入口：

| 入口 | 用户问题 | 默认内容 |
| --- | --- | --- |
| 首页 | 接着看什么？今天看什么？ | 继续观看、少量精选、最近添加 |
| 找片 | 我想找哪一部或哪一类？ | 搜索框、电影/剧集等分类、更多筛选 |
| 想看 | 我之前存了什么？ | 复用现有收藏；本期不新增第二套片单数据 |
| 我的 | 谁在看？如何调得更舒服？ | 个人资料、观看记录、字体与字幕偏好、设置 |

“找片”合并用户心智中的影视库和搜索入口，原搜索路由仍可由输入框进入。物理文件夹、存储来源、库名称收进找片的“范围”筛选。桌面与手机用同一名称和层级，按屏幕调整呈现方式。

首期把现有“收藏”入口命名为“想看”，保留原有数据与路由；不自动清空已看影片。若后续需要区分“喜欢”和“待看”，必须另行验证需求，避免制造两个近似按钮。

管理入口位于管理员的“我的 → 家庭管理”。管理员也默认进入观影首页，维护功能留在管理空间。后端权限是访问边界，隐藏按钮不代替权限校验。

## 4. 五条核心旅程

### 4.1 第一次加入家庭

目标流程：打开家庭链接或扫描配对码 → 接受授权/加入家庭 → 进入首页。

设备配对与家庭成员档案为后续新增能力，不能把现有注册表单换个名称就当作完成。邀请须可过期、撤销，配对不暴露长期登录凭据；已授权设备可记住家庭地址。公共设备提供退出与设备移除。

个人设备默认记住当前成员；共用电视可以显示成员选择。切换普通档案与进入家长/管理空间使用不同授权规则。孩子不能通过选择成人头像升级权限。

### 4.2 接着看

打开首页 → 点击“继续观看” → 从上次位置播放。

- 有观看进度时，继续观看排在内容区首位，不被大型推荐轮播挤下去。
- 明确显示片名、季集与剩余时间；时长未知时不编造剩余分钟数。
- 剧集完成后优先提供下一集；未完成时继续本集，完成判断复用并核实既有规则。
- “从头播放”作为次要操作，不在每次续播时弹窗询问。
- 从播放器返回时恢复来处、筛选、滚动位置；电视还需恢复焦点。
- 删除继续观看条目提供撤销，不删除影片文件。

### 4.3 不知道看什么

首页先给 3～6 个明确候选；可显示“你还没看过”“最近加入”等真实理由。避免一屏几十个栏目，也不默认自动播放预告或自动切换大海报。

“帮我选一部”作为后续可选操作：用户主动触发后展示一个候选，提供“播放”“换一部”。不直接随机播放，不强制填写兴趣问卷，不要求配置 AI。

推荐只使用当前成员有权访问的影片；无法确认片源状态时不标注“保证可播”。“全家一起看”只选家长认可或有可靠适龄依据的内容，不能把动画类型当作儿童安全标签。

### 4.4 已经知道要看什么

进入找片 → 输入片名 → 结果 → 播放。

基础搜索不依赖 AI；后续逐步补充别名、拼音与常见错字容错。结果先显示影片和剧集，演员等扩展结果不抢主位置。默认收起年份、地区、评分等组合筛选，并可一键清除。

搜索无结果应区分“当前筛选下没有结果”“家里还没添加这部影片”“搜索暂时不可用”。只有证据充分时才能给出具体原因。查不到不能暗示平台自动拥有或能下载所有影视资源。

### 4.5 点了以后看不了

点击播放 → 自动选择可用方式 → 必要时有限次切换兼容方案 → 成功或给出明确下一步。

继承已有降级机制，先核实跨播放器行为。自动恢复要保留播放位置，设定重试次数和整体等待上限，避免无限转圈。具体阈值通过本地、远程和低性能 NAS 的实际数据确定。

普通观众提示事实和操作：“正在准备播放”“这部影片暂时无法播放”，配“重试”“返回找片”。能准确识别网络故障时才提示检查连接。

管理员可展开诊断编号、来源状态与转码详情。普通观众可复制故障信息交给管理员；没有消息投递能力时，不显示“已通知管理员”。

## 5. 页面与交互规则

**首页**：当前成员与搜索入口 → 继续观看 → 今天可以看 → 最近添加。无历史时自然省略续播；无推荐时用可访问影片填补。新库整理中与真正空库、加载失败分开显示。

**详情页**：首屏回答“是什么、多久、能否开始”。片名、简短介绍、时长/季集、一个主要播放按钮和“想看”。有进度时主按钮写“继续播放”；剧集按钮可写“继续看第 3 集”。选集紧随主操作。演职员与相似影片在下方，技术规格进入“更多信息”。

**播放器**：优先显示播放/暂停、进度、音量/静音、字幕、全屏，剧集另有下一集；倍速等按需展开。画质默认“自动”，可提供“更清晰”“更流畅”，只展示底层实际支持的选项。字幕优先匹配已保存的语言偏好，可明确关闭；选不到时不能静默声称已启用。

**卡片**：点海报进入详情，明确的播放按钮才直接播放；继续观看卡片点按直接续播。相同上下文保持一致。关键操作在触摸和键盘下可见，不能依赖鼠标悬停。

**空状态**：管理员空库给“添加影片文件夹”；普通家人给“家里还没有可看的影片，请联系管理员添加”。已有文件整理中显示进度和已可观看内容；请求失败显示重试，不伪装成没有影片。

**确认与撤销**：收藏/取消收藏、调整筛选等低风险操作即时完成；删除原文件、移除成员、开放权限需要明确对象和后果。降低心智负担不等于取消关键保护。

## 6. 不同能力与共用设备

默认界面先做到易读、易点、稳定，再提供可选的大字模式；不强制按年龄分配“老人版”。

- 将触摸目标至少 44×44 CSS 像素、正文默认约 16 像素作为本项目初始设计目标，结合真机验证，不将这些数字表述为已通过认证。
- 支持字体放大、清晰焦点、键盘操作、屏幕阅读器名称；不能只靠颜色区分状态。
- 重点文案使用实体底色和稳定对比，玻璃背景不能牺牲阅读。
- 大字模式同步增加间距与点击面积，保留同样导航；尊重减少动画偏好。
- 电视需独立验证方向键、返回键、选集和字幕焦点；手机响应式页面不等于电视可用。
- 字体、字幕、自动连播偏好应有明确作用范围：跟成员保存，设备特有设置留在设备；共用设备不混淆成员进度。

儿童空间作为正式家庭能力单独验收：默认仅开放家长允许的库/内容；未分级内容待家长确认；限制同时覆盖列表、搜索、推荐、海报、详情、片段与播放接口。当前使用独立儿童账号，切换成人账号需要其密码；新建儿童账号默认关闭连播。现有每日时长为观看进度估算的参考限制，严格计时和家长独占连播开关仍待后续实现。

## 7. 管理员也要少操心

首次设置目标：选择影片文件夹 → 确认自动建议的名称和内容类型 → 开始整理并邀请家人。

默认完成基础扫描与资料匹配，部分影片就绪即可观看；不等待全库分析或预转码结束。错误识别允许单片修正。高级来源、语言、硬件加速等设置保留折叠入口。

普通文案用“查找新影片”“补全海报和简介”“播放准备”；管理员诊断详情仍保留精确术语。不能把不同任务全部笼统改名为“整理”而失去状态辨识。

默认不移动、重命名或删除原文件。耗时分析按需执行并限制资源；不能以自动化为名让 NAS 持续满载。管理首页优先显示“哪些影片可看、哪些需要处理”，再提供日志和任务详情。

## 8. 分阶段执行清单

优先级表达依赖与交付范围，不是未经估算的工期承诺。

| 阶段 | 交付项 | 完成标准 | 主要落点 |
| --- | --- | --- | --- |
| P0-1 | 桌面/手机统一首页、找片、想看、我的；范围筛选承接媒体库 | 所有既有核心页面仍可到达，旧路由和收藏数据保留，入口命名一致 | Sidebar、Layout、MyPage、BrowsePage、国际化资源 |
| P0-2 | 续播优先、自然季集文案、按角色和请求状态区分空页面 | 有历史能一键续播；普通用户不会被要求进入管理；失败不会显示为空库 | HomePage、首页组件、国际化资源 |
| P0-3 | 详情主操作聚焦，技术信息后置，播放器状态去术语 | 观众无需选择播放引擎；管理员仍能诊断；字幕与选集不变难找 | MediaDetailPage、SeriesDetailPage、PlayerPage |
| P0-4 | 核实续播、退出返回、有限恢复、重复点击行为 | 本地与远程样本通过；故障恢复不丢位置；无无限等待或重复会话 | 播放器、会话与历史链路 |
| P1-1 | 家庭配对、成员档案、设备撤销 | 非技术家人不必手输服务器地址；成员进度分离；授权可撤销 | 认证、服务端、客户端；需独立设计 |
| P1-2 | 儿童空间与端到端内容限制 | 未分级内容按儿童规则处理，不能经搜索/图片/直链绕过，切换成人需验证 | 正式服务端权限链路及所有客户端 |
| P1-3 | 大字模式、字幕偏好、电视遥控验收 | 放大后不遮挡操作；遥控完成找片、播放、返回、选集 | 设计系统、偏好存储及对应平台 |
| P1-4 | 添加文件夹引导与可操作故障反馈 | 不必先理解扫描和刮削；部分就绪即可看；维护问题明确归属 | CreateLibraryModal、管理中心、任务状态 |
| P2 | 搜索容错、帮我选一部、可选情境推荐 | 无 AI 配置也能完成基本找片；推荐尊重权限和真实内容状态 | SearchPage、搜索与推荐服务 |

P0 是最小闭环：打开 → 找到 → 播放 → 退出 → 接着看。P1 中儿童限制通过前，不对外承诺“可让儿童独立安全使用”；电视通过实际遥控验收前，不宣称已完成电视体验。

## 9. 怎么验证“家人真的会用”

先录制现状基线，再用同一批任务测改版。首轮建议 8～12 名具有不同年龄、视力和技术熟练度的用户，至少覆盖年轻使用者、中年使用者、长辈及家长陪同的儿童。小样本用于发现障碍，不冒充统计代表性。

测试人员只描述目标，不提示按钮位置：

1. 继续昨天没看完的那一集。
2. 找到指定影片并播放。
3. 不知道看什么时，选一部愿意看的影片。
4. 把影片留到下次看，再从想看中找回来。
5. 打开/关闭字幕，退出后重新进入并接着播放。
6. 遇到一次模拟播放失败，理解提示并完成下一步。
7. 管理员添加一个影片文件夹；家人加入并播放首部影片。
8. 儿童尝试搜索、直链访问受限内容与切换成人档案。

拟定验收目标（均非已测结果）：

| 指标 | 首轮目标或方法 |
| --- | --- |
| 核心任务独立完成率 | 前五项每项至少 90%，分别报告各人群失败原因 |
| 续播操作 | 已登录且首页有历史时，点击一次进入续播；不把等待时间算作点击 |
| 找片操作 | 首页到搜索结果中的指定影片开始播放，目标不超过 3 次明确操作，不计逐字输入 |
| 不知道看什么 | 从首页到选定内容的中位时间目标不超过 30 秒，拒绝所有推荐也记录原因 |
| 字幕与返回 | 不需要口头指导；返回后位置与焦点符合来处 |
| 播放可靠性 | 记录点击到首帧的中位数/P95、成功率、恢复成功率，按直放/转码、本地/远程及设备分组；先测基线再定性能门槛 |
| 管理员负担 | 记录一周内家人求助次数与原因，检查改版是否减少同类求助 |
| 儿童访问边界 | 已定义的受限内容/接口样本零越权；这只证明测试范围，不等于所有内容已完成分级 |

记录使用问题所需的最少信息；性能诊断优先使用匿名事件和技术状态，避免默认收集完整观影名称或家庭成员信息。
