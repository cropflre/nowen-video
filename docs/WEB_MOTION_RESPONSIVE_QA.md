# Web 动效与移动端适配回归检查

分支：`codex/family-viewing-platform`

本次只修改界面层。路由内的 Outlet 保持原有生命周期；页面转场仅在 pathname 改变时通过 Web Animations API 进行 180ms 的透明度/位移动画，搜索参数更新不触发动画。尊重系统“减少动态效果”，不改变服务端、播放/扫描、鉴权和数据流程。

## 核心视口

- 手机竖屏：320×568、360×740、375×667、390×844、414×896、430×932。
- 小屏横屏：667×375、844×390（播放全屏除外）。
- 平板：768×1024、820×1180、1024×768。
- 桌面：1280×800、1440×900、1920×1080。
- 另外检查 iOS Safari 安全区域、Android Chrome 地址栏收放、浏览器 200% 缩放以及大字体模式。

## 页面检查

1. 首页：首屏轮播、进度、继续观看横向卡片、媒体库入口；检查文字不撞按钮，触摸滚动横向轨道不跳动。
2. 找片/媒体库：媒体类型切换、筛选、搜索框、海报网格、加载骨架、分页；检查 320px 下两列、较宽手机三列及筛选无溢出。
3. 搜索：输入法弹出/收起、筛选项换行、结果卡片；检查不横向溢出、不缩放页面。
4. 影片/剧集详情：海报背景、播放/收藏操作、分区 Tabs、剧集横向列表、技术规格；检查标题与按钮不重叠，Tabs 可横向滚动。
5. 我的/收藏/历史/播放列表：统计块、操作区、历史卡片、内容末尾；最后一项不能被底部导航覆盖。
6. 文件管理/管理设置：工具栏、表格、弹窗、长文本与输入表单；检查弹窗在键盘打开和屏幕旋转后仍可滚动、关闭。
7. 播放器：返回、进度、倍速、字幕、清晰度菜单及横竖屏切换；不得改变已有播放器逻辑。
8. 底部导航：四项切换、当前态、连续点击、屏幕安全区域、大字体换行，确保没有跳动。

## 行为与性能

- 正常动画：切换不同页面时轻微淡入/上移，反复快速切换不残影，查询参数变化不重置状态。
- 在系统开启“减少动态效果”后，页面转场及弹窗/按钮动效停止，焦点可见状态保留。
- 鼠标悬停、键盘 Tab 与触屏分别验证；移动端播放按钮至少 44×44 CSS px。
- 弱网下 Suspense 页面加载提示、媒体骨架和交互反馈可见；注意避免不必要的大面积滤镜和持续动画。
- 每个视口在页面顶部、中部、底部检查 `document.documentElement.scrollWidth <= window.innerWidth`；横向媒体滚动轨道本身允许滚动。
- 刷新及来回导航后滚动恢复正确，筛选/分页/播放/收藏等原业务动作不受影响。

备注：提交前仅对源代码进行静态契约检查。完整构建、自动化浏览器截图以及真机验收需在可安装依赖/可登录服务的环境中执行。


## Android Compose 真机回归

- 320dp/360dp/393dp/430dp 宽度，系统字号 1.0/1.3/1.5；三按钮与手势导航分别检查底栏文字、选中态和触控区域。
- 首页首屏轮播高度随设备高度收敛到 420–500dp；播放/重播/收藏按钮和指示点必须完整显示。
- 首页、收藏、搜索切换时采用短淡入淡出，不应重建已保存的导航状态；进入详情/播放器仍使用已有路由动画及播放逻辑。
- 最后一条滚动内容不会被底部 dock 或系统导航区域盖住。检查旋转、低高度窗口、系统动画缩放为 0 的场景。
