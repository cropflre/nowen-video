# 家庭观影改造实施与验证记录

日期：2026-10-26。对应产品定义：`docs/FAMILY_PRODUCT_PLAN.md`。

本次交付 P0 观影闭环，并落地家庭邀请、账号观看偏好、文件夹引导和基础选片。下列状态区分已实现、自动验证和仍待实施/真机验收的能力。

## 已实现

| 范围 | 当前行为 |
| --- | --- |
| 主导航 | 桌面和手机统一为首页、找片、想看、我的；原收藏、搜索、媒体库路由继续可达，收藏数据继续复用 |
| 首页 | 继续观看优先，展示自然季集和剩余分钟；未知时长不编造数字；推荐不自动轮播；提供明确播放按钮 |
| 简单选片 | “帮我选一部”从最近添加内容中给出一个候选，可换一部、查看或播放；不会自动开始播放，不依赖 AI |
| 找片 | 搜索与筛选留在找片流程，避免同页重复搜索框；请求失败、真正空库、筛选无结果分开呈现 |
| 想看 | 原收藏内容继续可见；空状态提供找片入口；请求失败可重试 |
| 详情 | 主要操作突出播放和想看；预告、维护操作后置；技术信息与片段折叠；桌面和手机都保留实际可用的章节导航 |
| 播放 | 从服务端读取观看进度，未完成影片续播，完成影片从头播放；支持明确的“从头播放”；片段仍使用独立起止位置 |
| 失败恢复 | 准备播放最多等待 30 秒后提供重试与返回；自动网络重试有限次；重新尝试保留播放位置；普通观众不需要理解播放引擎 |
| 返回与误操作 | 返回找片时恢复列表位置；异步内容加载后继续恢复；创建文件夹、邀请和偏好保存避免重复提交；弹窗约束键盘焦点并恢复触发按钮焦点 |
| 空页面 | 普通观众联系管理员，管理员可进入实际的影片文件夹设置；网络故障不会伪装成没有影片 |
| 大字模式 | 字体、主要按钮与导航放大，支持 320px 布局验证；偏好按账号保存 |
| 字幕与连播 | 标准网页播放器支持自动、中文、英文、日文或关闭字幕；选不到指定语言时不自动换成其他语言；网页播放器支持关闭下一集自动播放 |
| 家庭邀请 | 管理员在“我的”创建 24 小时、一次使用的邀请链接；链接包含地址并预填邀请码；家人设置独立账号；未使用邀请可以撤销 |
| 邀请与注册边界 | 有效数据库邀请可在关闭公开注册时使用；不会修改公开注册配置；邀请占用与账号创建在同一事务中，重复/并发使用受限，创建账号失败回滚名额 |
| 添加影片 | 根据类型建议名称，保留手动改名；支持浏览文件夹；添加后自动发起查找；扫描启动失败保留已创建文件夹，并给出可操作提示；默认不配置原文件整理输出目录 |
| 多账号 | 页面缓存按账号隔离；切换身份时清理缓存、使旧请求失效并重新挂载观影视图；搜索缓存和滚动位置也按账号区分 |

账号偏好新增 `users.viewing_preferences` JSON 列，原账号空值使用兼容默认值。正式与兼容运行时共用模型；迁移不删除已有数据。邀请注册仍创建普通用户，不授予管理员权限。

字幕与连播设置当前作用于网页播放链路。指定字幕语言时，避免进入尚不支持字幕的 WebCodecs 播放器；桌面原生播放器和 Android 原生播放器的设置同步未在本轮完成。

## 自动验证

- `npm --prefix web run build`：TypeScript、生产构建、退役 UI 检查通过。UI 残留扫描是报告性质。
- `npm --prefix web run test:family`：5 项通过，覆盖续播边界、未知时长、异常进度、季集文案和字幕语言匹配。
- `npm --prefix web run test:media-tech`：既有 5 项通过。
- `go test ./internal/model ./internal/repository ./internal/service ./internal/handler ./cmd/server-lite`：5 个包通过，包含本次偏好持久化、身份保持、无效偏好、邀请过期/撤销、关闭公开注册时加入、并发限额和事务回滚验证。
- `npm --prefix web run test:family:browser`：18 组浏览器检查通过。结果与截图可写入 `FAMILY_QA_DIR`。
- `git diff --check`：通过。
- `npm --prefix web run lint`：现有 ESLint 9 命令无法启动，仓库缺少 `eslint.config.js/mjs/cjs`；未将其计为通过。

本次本地证据保存在 `data/family-product-2026-10-26/`（数据目录不纳入版本控制），包括 `report.json`、截图和验证日志。

浏览器覆盖 Chromium 1440px 桌面、390px 手机与 320px 窄屏。使用本地生成的 120 秒 H.264 MP4 验证真实视频进度；目录、影片资料、邀请与偏好接口使用可控测试响应。它不等同于真实 NAS、远程转码、Safari 或原生客户端验收。

浏览器检查另外覆盖：推荐不自动变动、搜索方向键不被首页拦截、选片不自动播放、键盘焦点、续播与从头播放、有限次网络恢复、字幕关闭与中文优先、偏好延迟返回、关闭自动下一集、保存失败回退、撤销邀请、扫描失败后不重复创建，以及前一个账号的请求延迟返回时不覆盖新账号内容。

复现浏览器验证需要 FFmpeg、Node 20+ 和 Playwright Chromium。先启动开发服务：

```bash
cd web
npm ci
npx playwright install chromium
npm run dev -- --host 127.0.0.1 --port 28917 --strictPort
```

另一个终端在项目根目录执行：

```bash
FAMILY_QA_DIR=/tmp/nowen-family-qa npm --prefix web run test:family:browser
```

自定义开发服务地址使用 `FAMILY_BASE_URL`。该测试读取 Vite 转换后的模块来隔离验证真实组件，目标必须是开发服务。输出包含 `report.json`、桌面/手机/详情/大字模式截图及生成的视频样本。
