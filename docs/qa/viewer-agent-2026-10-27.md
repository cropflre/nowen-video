# 家庭观影助手第一阶段

分支：`codex/family-viewing-platform`。本阶段为独立观影入口，不复用管理员文件助手。

## 用户能力

- 全站“问问助手”入口，保留原有首页、找片、想看和播放器按钮。
- 按片名、类型、年份、最低评分、电影时长上限和未看过条件找片，返回最多 6 张卡片。剧集进入详情选集；时长条件只用于电影。
- “继续看”列出当前账号可续播内容；“继续上次看的”打开最近一部，通过现有播放器恢复进度。
- “我的想看”、卡片加入想看，以及“收藏第二部”“把第二部加入想看”“第二部移出想看”等指代操作。
- 当前网页视频的暂停、继续、音量和静音；大字模式及中/英/日/自动/关闭字幕偏好。
- 只有接口成功或实际视频节点确认后，显示完成反馈。打开播放页只反馈已打开播放器，不宣称视频已开始播放。

## 实现边界

- Full / Lite 共用认证后的 `POST /api/agent/chat`，服务端从 JWT 上下文确定用户；请求中的用户、角色、影片引用均不能扩大权限。
- 模型只能返回经过校验的搜索条件。模型没有收藏、设置、文件、SQL、命令行或管理员工具。历史、想看、个人设置和播放指令走本地固定能力。
- 模型仅接收当前找片描述，不接收影视目录、路径、观看历史或其他家庭成员资料。搜索 SQL 在排序、分页之前应用当前账号的媒体库与分级范围；儿童共用现有 ChildCatalog，未审核内容和混合分级剧集继续隐藏。
- 每次聊天重新验证影片引用。点击卡片时，收藏和设置仍调用原有认证接口；播放进入原有播放器及儿童观看授权流程。
- 同一用户只允许一条聊天请求处理中；请求体最多 8 KiB，消息最多 500 字，上下文最多 6 个引用。AI 排队、冷却、限速及 HTTP 调用使用共同的 8 秒截止时间，失败自动基础找片，不留下后台悬挂请求。
- AI 沿用管理员配置的 AI 与智能搜索开关。未配置、关闭、预算耗尽、无效输出或调用失败时，基础找片和日常指令仍可用。
- 对话只存在当前网页内存中，关闭面板保留，清空/刷新/切换账号后消失。离开当前播放页后不执行旧页的播放指令；切换账号取消旧聊天并丢弃迟到结果。
- 不支持电视遥控、原生客户端播放器或 WebCodecs 画布播放控制；没有可控制的视频节点时明确提示使用播放器按钮。字幕偏好保存成功与影片存在相应字幕是两个状态。
- 不包含删除、重命名、扫描、下载、家长设置和设备授权等管理操作，也未引入自动执行后台任务。

## 验证

后端使用真实 SQLite 权限/历史/想看数据验证 SQL 范围及账号隔离；AI 使用本地 HTTP 协议测试服务验证搜索条件、非法输出降级及取消，不调用真实云端模型。

浏览器测试使用真实 Chromium、真实页面和 MP4 视频节点，API 使用可失败的测试夹具。覆盖第二部指代、收藏成功/失败、模型降级/空结果、320px 大字模式、字幕失败回滚、键盘焦点、真实暂停/续播/音量、儿童观看授权拒绝、账号切换中的迟到指令及观看进度恢复。

已通过：后端 model/repository/service/middleware/handler/Emby/Full/Lite 共 8 个包，前端构建（含 TypeScript、retired-ui 检查，UI audit 为 report-only），10 个前端单元用例及 38 组浏览器场景（原有 32 组 + 助手 6 组）。

新增的权限隔离、模型降级、精确片名、续播及请求取消用例另通过 `go test -race ./internal/service ./internal/handler -run 'TestViewerAgent|TestAIContext' -count=1`。最终微调后重复助手 6 组及前端构建。

浏览器报告和截图位于 `/tmp/nowen-viewer-agent-full-qa`；构建及后端日志位于 `/tmp/nowen-viewer-agent-*.log`。这些本地结果不代表真实模型服务、电视、原生客户端、生产 NAS 或发布验收。

## 真实百炼联调补充

使用用户提供的北京业务空间 OpenAI 兼容地址与百炼密钥验证。凭据仅在测试子进程内存中使用，未写入代码、报告或 Git；请求限定为用户指定的 HTTPS 域名，未发送真实家庭影视目录。

- `GET /models` 返回 HTTP 200，并取得 180 个模型条目，说明该地址可以完成密钥鉴权。模型列表可读不等于模型推理可用。
- `qwen-flash` 与 `qwen-plus` 的聊天推理均返回 HTTP 403，错误码 `insufficient_quota`；百炼提示免费额度用完，需要处理“仅使用免费额度”限制或账户付费状态。
- 在真实云端返回 403 的情况下，实际 `/api/agent/chat` 处理链配合隔离 SQLite 测试目录，仍能返回 HTTP 200 / `mode=fallback`：按 90 分钟以内、没看过、喜剧条件及 2014 年科幻电影条件均取得正确结果，儿童不可见内容继续被过滤。
- 个人收藏指令未额外调用模型；测试没有更改真实收藏、家长权限或影片。
- **云端推理联调尚未通过**。未将不可用模型保存为本地有效配置，也未修改百炼付费、充值或免费额度开关。后续需由账号持有人确认模型可用额度或付费设置后重试。

脱敏报告及可重复执行的本地验证脚本位于忽略跟踪的 `data/agent-live-2026-10-27/`。额度处理规则参见[阿里云官方说明](https://help.aliyun.com/zh/model-studio/new-free-quota)。

后续用户指定 `deepseek-v4.1-flash-1017`，已完成真实百炼调用及 NAS 联调；当前结果与现场发现的修复见[真实环境验收记录](family-real-acceptance-2026-10-27.md)。上文 403 为此前两个 Qwen 模型的测试结果。
