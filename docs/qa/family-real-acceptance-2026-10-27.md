# 家庭影视平台真实环境验收

## 环境与数据边界

- 本机 macOS arm64、真实 Chromium，使用当前分支编译的 Lite 后端和真实前端；本轮脚本不拦截或模拟 API。
- NAS 沿用 `/Volumes/16t` 的现有 SMB 挂载；当前库有 100 部影片。选择两部真实 H.264/AAC MKV 作为文件读取与权限样本，视频尺寸为 864×596。
- 使用 SQLite 在线 backup 制作独立数据库副本；新增的管理员、普通观众、儿童账号及测试分级只存在该副本。测试中的 G/R 标记用于验证权限，不代表影片已经经过人工适龄审核。
- 测试副本禁用媒体库文件监听；缓存和播放中间文件写入独立目录。原文件只读，原数据库与两个 NAS 样本的大小、修改时间另行比对。
- 隔离服务为 `127.0.0.1:28928/28929`，原有 `28888/28889` 服务在隔离验收期间保持运行。

## 本轮发现与修复

1. 不存在的 API 原来返回首页 HTML / 200，可能掩盖旧服务或错误地址。Full/Lite 现在对缺失 API 返回 JSON / 404，正常前端深链接继续返回页面。
2. 播放器全局快捷键会抢占聊天输入，Escape 同时关闭助手并退出播放器。普通视频、会话视频与 WebCodecs 快捷键统一让弹窗和输入控件优先处理按键。
3. 默认 HTTP 日志会记录带临时 token 的图片/播放 URL。Full/Lite 访问日志现在保留方法、路径、状态和耗时，不记录查询参数及认证头。
4. 最后一次儿童观看续期可能与额度到期同时发生，较晚响应会覆盖已经显示的停止原因。服务端优先报告每日额度耗尽，网页保留首次停止原因并忽略停止后的迟到授权。
5. 百炼模型可能把搜索布尔值返回成 0/1，导致正确的复杂筛选被整体丢弃。现在明确提示 JSON 字段类型，只归一化精确的 0/1；其他错误类型继续拒绝。基础找片同时补齐年份范围和中文评分下限解析。

## 真实模型

用户指定 `deepseek-v4.1-flash-1017`，通过其北京百炼业务空间的 OpenAI 兼容地址调用。连接探针、三个自然语言找片条件均返回 HTTP 200；个人收藏指令不额外调用模型。服务商标识保持百炼兼容适配器，模型名称使用用户指定值。

已验证：中文“九十分钟以内”、没看过、类型、年份范围、评分至少八分及儿童范围过滤。另通过真实聊天界面查询实际 NAS 库，结果符合电影时长上限。模型只接收找片描述，不发送目录、真实文件路径或其他家庭成员资料。

本地 AI 配置通过现有加密机制保存到忽略跟踪的数据目录，权限为 0600，并重新加载核对；只开启智能找片，自动整理、元数据 AI 和供应商自动切换保持关闭。此前 `qwen-flash/qwen-plus` 的额度错误仍是这两个模型的实测结果，不代表当前所选 DeepSeek 模型不可用。

## 验收范围

真实浏览器覆盖健康检查与鉴权、三类账号登录、库检查及管理员隔离、自然语言找 NAS 影片、想看增删、偏好持久化与 320px 显示、MKV 自动 Remux、聊天控制真实视频、观看记录续播、儿童列表与直链隔离、一分钟真实计时停止、家长撤权、配对一次领取和逐台退出。

“进入到视频已解码且播放超过两秒”的采样耗时只用于确认实际播放，不作为首帧或 P95 性能结论。浏览器宽度模拟不能代替 Android、Safari、实体电视和遥控器验收。

最终报告、截图和脱敏日志保存在忽略跟踪的 `data/family-real-acceptance-2026-10-27/`。真实验收脚本为 `web/scripts/family-real-acceptance.browser.cjs`，需要显式提供隔离环境的 `FAMILY_REAL_MANIFEST`；拒绝对非 loopback 服务运行测试。

最终结果：真实环境 **15/15 组通过**；既有浏览器回归 **38/38 组通过**；前端 10 个逻辑用例及 TypeScript/Vite 构建通过；相关 8 个 Go 包通过；Agent、管理员检查、家长额度、API 回退及日志保护的相关用例通过 race 检查。

## 原有本机开发实例更新

隔离验收通过后，为原数据库制作 SQLite 一致性备份并保留旧服务二进制，再通过项目 `scripts/dev.mjs` 更新原有 `28888/28889` 实例。备份及升级报告位于忽略跟踪的 `data/local-family-upgrade-2026-10-27/`。

- 更新前后，使用同一枚不带设备 sid 的短期兼容验证令牌读取原账号均成功；该验证令牌未输出，验证文件已删除。
- 原有 1 个账号、100 部影片，以及媒体库、观看记录和收藏的既有字段逐项比对一致。数据库完成当前版本所需迁移，未创建测试家庭成员或更改真实分级。
- 原实例的 Agent 库检查返回 100 部影片，真实百炼自然语言找片返回 `mode=ai`，确认新代码和新模型配置均已加载。
- 前端与前端 API 代理均返回 200，代理仍指向 28888；新开发服务日志未出现查询参数凭据。

此操作更新本机开发服务，不等同于发布 Docker/NAS 生产包、Android 或电视版本。独立验收实例在完成后关闭，原有本机开发服务继续运行。

## 管理型 Agent 的本轮推进

首批管理能力为只读检查：管理员可说“检查影视库”，查看真实库数、影片数、资料待补和分级待审核数量，并进入对应影视库；“检查任务”从现有任务中心读取实际运行与失败情况。普通观众和儿童请求在服务端拒绝，模型不获得管理权限。

扫描、资料补全、重命名、移动和删除仍需后续接入持久化任务、对象预览、确认绑定、执行结果与适用的撤销机制。本轮不把只读检查表述为完整管理型 Agent 已交付。
