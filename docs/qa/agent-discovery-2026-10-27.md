# 管理型 Agent：查找新电影

## 当前交付

管理员在“问问助手”中说“查找新影片”，选择电影库后得到服务端预览：库名、文件夹、文件大小过滤规则、实际操作范围及确认有效期。确认后后台执行，关闭页面不影响已启动任务；重新打开助手可查看持久化回执。

本阶段只登记新发现的电影，跳过已有记录，保留离线记录和原文件。沿用现有标题/NFO/字幕读取与探测能力，但不运行在线资料补全、AI 整理、文件改名/移动/删除、合集整理或扫描后置回调。新增记录不会自动获得儿童内容分级。

支持 `movie/other` 类型及本机绝对路径、已挂载的 NAS 文件夹；剧集库、混合库和未挂载的远程路径仍使用原有管理流程。多个路径逐个遍历，影片逐个探测；重叠路径去重。Agent 扫描进度和回执不向普通观众的全局事件通道广播。

## 授权与持久化

- Full/Lite 迁移核心表 `agent_runs`，不依赖 AI 开关或模型可用性。
- `/api/admin/agent/runs` 提供预览和本人最近 20 条任务，`/:runID/confirm` 确认，`/:runID/cancel` 取消尚未执行的预览。
- 服务端重查管理员身份、儿童标志、禁用/强制改密状态；审批绑定发起用户、账号权限版本、任务类型、库配置快照及有效期摘要。模型只负责找片，不生成或批准管理操作。
- 预览十分钟有效。库配置变化或账号权限版本变化后须重新预览；其他管理员不能确认或读取该用户的任务。
- 确认通过数据库事务一次性领取执行权。重复确认只返回已有回执，同一库的并发 Agent 任务通过数据库唯一键互斥，执行时另复用普通扫描锁。
- 状态包括等待确认、执行中、完成、失败、取消、过期和中断。只在扫描真实返回后记录完成及新增数量，失败保留实际已登记数量。
- Worker 每十五秒续期，两分钟失联后在任务查询/确认时标记中断并释放 Agent 占用。不会自动重新执行；重新预览是独立的用户操作。已中断任务的迟到结果不能覆盖中断回执。
- 运行中的扫描暂不支持中途取消，预览已明确提示。失败或服务中断后可能已有部分影片入库，重试会跳过已有记录；不提供会影响后来收藏/观看数据的自动删除式回滚。

任务历史默认可收起，新的待确认/运行任务自动展开。320px 下输入框保持可见，预览内可滚动核对文件夹及确认按钮。清空聊天不会删除服务端回执。“检查任务”同时报告本人最近助手任务和可用的任务中心状态。

## 验证

- 真实 SQLite/HTTP：普通观众和儿童拒绝、管理员间隔离、摘要伪造、库配置变化、账号权限撤销、强制改密、预览过期、取消后重放、八个并发确认只执行一次、同库互斥、部分失败及失联后不自动重跑。
- 真实 FFmpeg MP4 入库：只登记一个新文件，保留已有记录的标题/大小/评分及离线记录；重叠路径不重复登记，重复扫描新增为零；不广播全局事件、不运行后置回调、源文件字节不变。
- 实际后端与 Chromium（没有 API 模拟）七组场景通过：权限、预览不执行、取消、确认与重放、320px、刷新后回执、重复扫描、文件夹断连失败及恢复后重新预览、源文件保留。
- 另验证实际后端进程重启后回执仍在，重放完成任务保持原结果，手机宽度下输入框可见。
- 相关八个 Go 包、上述服务/HTTP race 用例、前端构建和既有 38 组浏览器回归通过。

本地报告与截图位于忽略跟踪的 `data/agent-scan-acceptance-2026-10-27/`。脚本 `web/scripts/agent-scan.browser.cjs` 必须显式提供隔离 manifest，拒绝原开发服务端口。此次自动执行只针对隔离测试库，未代替用户确认并扫描真实 NAS 影视库。

## 本机服务更新

已为原数据库和旧服务程序建立回滚备份，然后通过项目启动脚本更新 `28888/28889` 本机开发实例。升级后原有兼容会话仍有效；任务历史接口可用，聊天返回预览准备动作。真实库的 `agent_runs` 数量为零，表示上线检查没有启动或创建真实扫描任务。

原有一个账号、100 部影片，以及媒体库、观看记录和收藏的既有字段逐项核对一致，前端及 API 代理均为 200。临时验证凭据已删除，验证报告与备份位于忽略跟踪的 `data/agent-discovery-local-upgrade-2026-10-27/`。没有提交代码、发布制品或改动 main。

## 后续范围

资料补全、完整扫描、重命名、移动及删除分别需要准确的影响预览、资源预算、任务协议和相应撤销能力，尚未接入此 Agent 执行链。本轮不将“只登记新电影”表述为影视库的全部管理操作。
