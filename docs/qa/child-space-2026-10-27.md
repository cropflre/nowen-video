# 儿童空间实施与验证记录

日期：2026-10-27。接续 [家庭观影改造](family-product-2026-10-26.md) 的下一阶段，本次完成独立儿童账号、家长分级与内容访问隔离。本地代码与自动验证已完成，尚未发布。

## 家长如何使用

1. 在“我的 → 家庭管理 → 用户管理”创建用户，打开“创建为儿童账号”。也可在已有普通用户的“权限”中打开“儿童空间”。管理员账号不能开启儿童模式。
2. 在儿童账号的权限中明确选择影片库，选择最高允许分级 G、PG 或 PG-13，并保存。新账号未配置影片库时无法观看；已有账号的权限每次保存后都需要重新登录。
3. 使用管理员账号打开电影详情的“更多信息与片段”，选择并保存“家庭内容分级”。剧集详情的“家庭内容分级”可统一确认当前所有集；请先检查这些内容。选择“未确认 / 撤回确认”可撤回。
4. 使用儿童账号登录网页。首页、找片、想看和观看历史只显示授权范围内的内容。切换成人账号必须使用该账号的登录凭据；没有点击成人头像直接升级权限的入口。

分级由家长判断，不按“动画”等类型自动判定适龄，也不声称影片已经过平台人工审核。既有管理员保存的内容分级继续作为确认记录。

## 当前行为

| 范围 | 行为 |
| --- | --- |
| 默认权限 | `users.child_mode` 为服务端权威字段。新儿童账号没有开放的库，默认关闭网页自动连播；未知分级、缺少权限记录或无法确认权限时拒绝放行 |
| 内容列表 | 在 SQL 查询中先应用库和分级限制，再计数、排序、分页；搜索、推荐、继续观看、想看、历史使用同一范围，不泄漏受限影片标题和数量 |
| 剧集 | 所有现有单集均在开放库且分级合规后，才开放整剧的共享简介、海报与单集。新扫描的未分级集会暂时让整剧退出儿童空间，重新确认后恢复 |
| 直链与播放 | 详情、图片、片段、播放信息、直放、兼容流、字幕均检查内容范围；外部字幕必须属于已授权影片。会话状态、心跳、重启、播放列表和分片重新检查当前媒体权限 |
| 撤回 | 分级撤回后后续受检请求拒绝。网页播放器每 15 秒及窗口重新获得焦点时检查，收到 403/404 后停止播放并显示提示；网络故障不冒充撤回。不能撤销已经下载的字节，后台页面定时器可能被浏览器延迟 |
| 账号权限变更 | 权限与儿童标志在同一事务中保存，并递增令牌版本。旧令牌失效；自助资料接口不能修改儿童标志或角色，仍为儿童的账号不能直接升级管理员 |
| 事件与缓存 | 儿童禁止订阅全局事件；既有普通账号事件连接在发送前检查账号状态和令牌版本。儿童首页使用静默轮询更新；儿童响应强制 `private, no-store`，账号变化清除页面缓存 |
| 菜单 | 儿童隐藏管理、文件、统计、播放列表等当前不支持的页面；相关服务端入口拒绝或返回空数据，新增未明确允许的业务接口默认拒绝 |
| 记录 | 家长权限与内容分级保存写入管理审计 |

## 兼容性与限制

- 儿童账号当前仅承诺网页核心观影链路，禁止 Emby 兼容登录和携带已有令牌访问兼容接口，避免第三方客户端绕过内容范围。Emby 公共用户列表不展示儿童。
- **所有账号的 Emby 海报接口现在均要求认证**，响应为 `private, no-store`。第三方客户端必须随图片请求提供有效令牌；依赖匿名图片的客户端需要适配。尚未完成各第三方客户端真机兼容验收。
- “每日观看时长参考限制”沿用观看记录中的进度估算，不能等同于可靠的实际观看计时或防篡改家长控制。读取记录失败时拒绝继续放行，但仍需要后续专门实现严格计时。
- 新建儿童账号默认关闭连播；当前连播仍是账号可自行修改的观看偏好。家长独占开关、共用账号档案、家长 PIN、设备配对、单设备撤销、原生播放器偏好和实体电视遥控验收仍待后续阶段。
- 自动验证使用 SQLite 测试数据库、HTTP 测试路由和浏览器模拟 API，没有更改本地真实家庭成员权限或影片分级，未执行生产部署或发布。
