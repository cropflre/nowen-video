# 管理型 Agent：逐片补全空缺文字资料

分支：`codex/family-viewing-platform`。这是“查找新影片”之后的独立执行能力；没有将旧的覆盖式刮削直接暴露给聊天。

## 使用流程

管理员在“问问助手”中说“补全资料”，选择一部电影的“预览资料补全”；也可说“补全第二部资料”，或在电影详情/当前播放页说“补全这部资料”。候选最多六部，仅包含电影库/其他类型库内，已关联 TMDb 且有空缺文字资料的电影。

预览读取当前 TMDb 条目，展示平台片名、资料源片名、可打开的 TMDb 来源链接及逐字段变化。确认后将预览中的值原子保存到数据库，任务记录会保留；确认不再次请求资料源，不依赖 AI 开关或模型。关闭/刷新聊天后仍可查看回执。

本轮字段为简介、原名、类型及首映日期，只补空值。已有资料、片名、年份、评分、图片、演职员、播放技术信息、观看/收藏和儿童分级不变；不调用覆盖式 ScrapeMedia、图片下载、AI 整理、NFO 写入或全局广播。未关联 TMDb 的影片需先在现有资料页面确认匹配，不按搜索结果自动猜测身份。

## 确认和撤销

- 复用 Full/Lite 的 `agent_runs` 核心表，新增隐藏的服务端 proposal 字段保存资料来源及确切变化；列表只向本人管理员返回可审阅视图。
- `POST /api/admin/agent/runs/metadata` 创建预览，使用原任务确认/取消接口；`POST /api/admin/agent/runs/:runID/undo` 撤销已完成的本次补全。
- 来源读取有八秒截止时间、1 MiB 响应限制和条目 ID 校验；跨主机/协议重定向不携带凭据继续请求。资料源错误统一提示，不回显密钥、URL 查询参数或内部错误。
- 十分钟审批绑定发起人、账号权限版本、操作类型、影片身份/更新时间/四个字段及 NULL 状态、影视库配置、来源值和期限。确认时再次核对身份、禁用/强制改密/儿童标志、权限版本和数据快照。
- 确认与回执在同一事务内完成，更新再检查影片版本和预期字段。重复或八次并发确认只应用一次；取消、过期、配置变化或资料已被修改的预览不会覆盖现状。
- “撤销本次补全”仅恢复本次填写的字段；恢复前逐项确认这些字段仍是本次填写的值，任何一项变化就整体拒绝，不会部分撤销。保留其他字段后续编辑，支持精确恢复空字符串、空格和旧 NULL。
- 撤销也校验本人管理员及账号权限版本，使用原审批摘要，重复撤销返回原回执。撤销状态为 `reverted`；不创建删除媒体或修改文件的回滚任务。

## 验证

- 相关八个 Go 包通过；资料补全与原扫描服务/HTTP 用例通过 race 检查。
- SQLite/HTTP 覆盖预览无写入、已有字段保留、来源错误/条目错误、普通成员/儿童拒绝、管理员间隔离、摘要伪造、权限版本/禁用/强制改密/角色变化、库配置变化、影片变化、过期、取消、八次并发确认、持久化回执、重复撤销、后续编辑保护和旧 NULL 恢复。
- 资料源客户端协议用例验证 GET/认证查询/语言/条目路径、响应大小及上下文取消；资料源不执行图片、文件或数据库写入。
- 最终实际后端 + Chromium 九组通过，没有模拟应用 API；资料源是本机 HTTP 夹具，不代表真实 TMDb 联调。覆盖聊天指代、字段预览、确认/取消、重复请求、320px、刷新后撤销、陈旧预览、后续编辑导致撤销被拒、来源失败、原文件/NFO 字节及儿童分级不变。
- 实际隔离后端重启后四条回执仍在，已撤销状态保留，重复确认不改变原执行时间、不重新读取资料源。
- 原有 38 组浏览器回归、10 个前端逻辑用例、TypeScript/Vite 构建通过。UI audit 仍为原有 report-only，不将其当作 lint 通过。

隔离报告、截图、配置与测试数据位于忽略跟踪且权限受限的 `data/agent-metadata-acceptance-2026-10-28/`。脚本 `web/scripts/agent-metadata.browser.cjs` 要求显式隔离 manifest，拒绝非 loopback、原 28888/28889 端口及不在隔离目录中的数据库。

## 本机服务更新

已确认原后端没有读取 NAS 影片或运行转码，再为原数据库制作一致性备份、保留旧程序，更新原 28888 后端，保留 28889 网页服务。原账号的短期兼容会话、经网页代理的资料补全命令及任务历史接口均通过；验证凭据只存在内存。

原有一个账号、两个库、100 部电影、八条观看记录，以及收藏、内容分级、权限和任务表的既有字段逐项摘要比对一致；原真实库任务仍为零，没有对真实影片请求资料源、创建预览或执行补全。回滚备份及核对结果位于 `data/agent-metadata-local-upgrade-2026-10-28/`。

**当前真实库的 100 部电影都没有 TMDb 关联，因此候选列表为空。** 这是范围限制，不能声称真实 NAS 资料补全已验收。需要管理员先确认影片匹配，之后才能使用本轮功能；本轮没有自动猜测或批量修改这些电影。
