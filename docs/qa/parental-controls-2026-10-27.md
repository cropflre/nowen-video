# 家长控制：服务端计时与连播

日期：2026-10-27。接续 [儿童内容隔离](child-space-2026-10-27.md)，本阶段为儿童账号接入服务端观看额度与家长独占的连播设置。当前为本地实现和自动验证，尚未提交或发布。

后续网页设备配对和逐台退出见 [设备配对记录](device-pairing-2026-10-27.md)。下文未完成设备配对的描述保留为本阶段完成时状态。

## 如何使用

在“我的 → 家庭管理 → 用户管理 → 权限”打开儿童空间，设置“每日可观看时间（分钟）”和“自动播放下一集”，然后保存。0 表示不限制；非零为所有设备共用的每日额度。保存仍会使旧登录凭据失效，孩子需要重新登录。

儿童的“我的”展示当天已计入和剩余时间，以及服务器的日期、时区。连播开关显示家长的选择，儿童不能自行修改；大字模式和字幕偏好仍可调整。额度耗尽时显示休息提示，返回找片仍能查看已经授权的影片资料。

## 计时规则

- 新增独立的每日用量与播放授权表，Lite 和 Full 启动均迁移。旧观看历史保留，不能用于推算可靠的实际时长，所以不会把旧进度导入新额度。
- 按服务器时钟计算“授权观看时间”，不接受客户端传入的观看秒数、播放进度或日期。拖动、倍速、重播、删除历史、刷新和切集不会清除当天用量；数据库记录在服务重启后继续生效。
- 每次最多预留 15 秒，网页每 5 秒申请续期。只有一个账号级授权可同时有效，其他播放页需要先暂停原播放，或等待授权过期。续期延长同一个连续区间，不会对每次心跳分别向上取整而多算时间。
- 正常暂停时结算并退回未使用的预留秒数，连续区间按秒向上取整。未正常退出、丢失暂停请求或断网，最多计入最后一次授权中尚未使用的 15 秒。准备播放、缓冲和跳转期间的授权时间可能计入，不能把本功能表述成精确测量用户实际观看了多少画面。
- 暂停后恢复或跳转会先重新获得授权。限时模式下暂停后跳转将继续播放；客户端不会在没有授权时启动新的兼容流或转码跳转。
- 额度使用服务器当前时区的自然日，跨日授权截断到午夜，新一天可重新开始。没有历史回填、跨日自动连播或家长修改时区的专门配置。
- 限额耗尽、授权过期、无法读取计时数据或续期失败时，网页停止播放并给出下一步。后台页面会暂停并结算，重新获得焦点也会检查授权是否过期。

## 服务端边界

新增接口均使用当前登录账号，不能通过请求体指定另一位家庭成员：

| 接口 | 用途 |
| --- | --- |
| `GET /api/users/me/family-controls` | 当天额度和家长连播设置，不返回其他页面的授权标识 |
| `POST /api/users/me/viewing/start` | 为已获准影片预留短时观看额度 |
| `POST /api/users/me/viewing/renew` | 校验当前内容权限并续期 |
| `POST /api/users/me/viewing/stop` | 结算自己的授权；旧标识不能关闭新授权 |

限时儿童的新直放、兼容流、片段预览、会话创建/重启及媒体分片请求必须有匹配影片且未过期的授权。会话状态与暂停心跳只检查当前内容权限，允许暂停后保活，但不因此放开媒体分片。取消内容分级后，暂停心跳也不能绕过权限。

家长连播标志存于权限表；儿童自助资料提交中的连播值不能覆盖它。登录、刷新和读取资料均返回服务端计算的值。旧管理客户端省略新字段时保留已有选择，迁移默认关闭。

此规则约束正式网页播放器和后续服务请求，不能召回已下载的文件、缓存字节或强制停止被修改的第三方客户端。不是 DRM，也不宣称能识别用户是否真的在屏幕前。未设置每日限额的儿童仍可观看，服务端不会追记无限额期间的时间。

原生播放器尚未接入完整计时链路：设置了时间限额的儿童账号在桌面原生播放器中提示使用网页端；限时网页播放使用可统一控制的 HTML video 路径，不进入独立 WebCodecs 播放壳。儿童 Emby 登录继续禁用。Android、电视及真实 NAS/转码设备仍需后续适配和验收。
